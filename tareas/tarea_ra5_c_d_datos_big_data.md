# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Instagram
- Contexto: Guarda con un sistema de puntos el contenido que te gusta por ejemplo si das like a contenido con #futbol te recomedara mas post de futbol, y asi con tod con visulaizaciones, comentarios, etc.

## 2) Conceptos
- Big Data: Se almacena todos los contenidos de todas las personas.
- Análisis de datos: Teniendo todos los datos empezara a calcular el algoritmo de recomendacion con puntos.
- Machine Learning: Aprende con el tiempo que tipos de perfiles son los mas recomendados para cierto publico y para cual no, aparte de otras muchas mas cosas.
- Deep Learning: Analiza el comportamiento humano con cuentas, posts, etc. Basicamente un ejemplo es cuanto tiempo llevas viendo un video, un post, has hecho zoom, analiza la imagen, cosas que como tal una maquina no debe fijarse por que no es una base estructurada de datos.
- IA: Y la IA es el ultimo paso es el que decide que contenido se muestra primero, cual no, etc.

## 3) Relación
- Los usuarios generan datos → Los almacena → Se analizan → Se entrenan modelos de _MachineLearning/DeepLearning_ → La IA decide que contenido mostrar

## 4) Pipeline
*Datos masivos → Procesamiento → Análisis → Modelo ML/DL → IA → Decisión*
1. *Datos* (likes, comentarios, visualizaciones)
2. *Procesamiento* (organización de datos)
3. *Análisis* (detectar intereses)
4. *MachineLearning/DeepLearning* (predicción de gustos)
5. *IA* (sistema inteligente)
6. *Decisión* (feed personalizado)

## 5) 5V del Big Data
- Volumen: Millones de publicaciones y usuarios.
- Velocidad: Datos generados al instante scroll, likes, etc.
- Variedad: Fotos, vídeos, mensajes, stories.
- Veracidad: Filtrar cuentas falsas o spam.
- Valor: Mejorar recomendaciones y publicidad.

## 6) Ejemplo aplicado
- Datos: Reels que ves completos y cuentas que sigues.
- Análisis: Detectar que te gusta el fitness.
- Modelo: Algoritmo de recomendación.
- Decisión: Mostrar más contenido de ejercicio

## 8) Diagrama
- *Juan98* > *Like a Luisa_00* > *El contenido de Luisa se añade a la memoria de recomendacion de Juan98* > *El sistema le empezara a recomendar contenido de mujeres, del año 2000, y españolas* > *Le recomienda fotos de ella en la playa ya que es lo que mas a mirado* > *Los post y las historias de Luisa le van a salir muy arriba en los recomendos* > *Le empieza a recomendar mas contenido parecido al que esta consumiendo*
## 9) Problemas
- Problema 1: Datos falsos (bots).
- Solución 1: Sistemas de detección automática.
- Problema 2: Sesgo en recomendaciones.
- Solución 2: Introducir contenido variado.
