# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Instagram
- Contexto: Guarda con un sistema de puntos el contenido que te gusta por ejemplo si das like a contenido con #futbol te recomedara mas post de futbol, y asi con tod con visulaizaciones, comentarios, etc.

## 2) Conceptos
- Big Data: Se almacena todos los contenidos de todas las personas.
- Análisis de datos: Teniendo todos los datos empezara a calcular el algoritmo de recomendacion con puntos.
- Machine Learning: Aprende con el tiempo que tipos de perfiles son los mas recomendados para cierto publico y para cual no, aparte de otras muchas mas cosas.
- Deep Learning: Analiza el comportamiento humano con cuentas, posts, etc. Basicamente un ejemplo es cuanto tiempo llevas viendo un video, un post, has hecho zoom, analiza la imagen, cosas que como tal una maquina no debe fijarse por que no es una base estructurada de datos.
- IA: Y la IA es el ultimo paso es el que decide que contenido se muestra primero, cual no, etc.
